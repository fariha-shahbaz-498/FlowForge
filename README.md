# 🚀 FlowForge – AI Powered Project Management Platform

## 📌 Overview

FlowForge is an AI-powered project management platform that helps students, freelancers, startups, and small teams organize their work in one place.

The application allows users to manage projects, tasks, team members, meetings, and deadlines while receiving AI-powered productivity assistance.

---

# 🎯 Problem Statement

Managing projects using multiple spreadsheets, chats, and notebooks becomes difficult as teams grow.

FlowForge solves this problem by providing one centralized workspace where users can:

- Manage projects
- Track tasks
- Organize meetings
- Monitor progress
- Collaborate with teams
- Get AI-powered productivity suggestions

Target Users:

- Students
- Final Year Project Groups
- Freelancers
- Startups
- Small Businesses

# 🚀 Installation

Clone repository

```bash
git clone https://github.com/YOUR_USERNAME/FlowForge.git
```

Install frontend

```bash
cd client
npm install
npm run dev
```

Install backend

```bash
cd server
npm install
npm run dev
```

---

# 🔐 Environment Variables

Create a `.env` file inside `server`.

```env
PORT=5000

MONGO_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET_KEY
```
